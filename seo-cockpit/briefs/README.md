# Briefs

This folder holds execution-ready briefs for editors, agents, or future automation steps.

## Purpose
Briefs should turn audit findings into one concrete deliverable.

A good brief:
- names one target file or one new file path
- names the keyword or query cluster
- states the search intent
- defines what should change
- defines what should not change
