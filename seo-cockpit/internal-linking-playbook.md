# Internal Linking Playbook

Use this rule set for every new or refreshed blog article on `agadirlocalguide.com`.

## Universal Rules
- Every article must link to `2-4` other blog posts.
- Every article must link to `1-2` relevant tour or commercial pages.
- One of the links should support a priority hub or money page.
- The first useful tour link should appear before the midpoint of the article.
- Use natural anchor text. Prefer partial match or descriptive anchors.
- Do not force the same exact anchor into every article.
- Related articles and sidebar links help, but they do not replace in-body contextual links.

Use these often when relevant:
- `blog/agadir-day-trips.html`

## Anchor Text Rules
Good anchor patterns:
- `Paradise Valley guide`
- `Agadir day trips`
- `Agadir city tour with cable car`
- `Marrakech day trip from Agadir`
- `things to do in Agadir`

Avoid:
- repeating the same exact keyword 3 or 4 times
- vague anchors like `click here`
- stuffing links into one paragraph

## Default Link Pattern Per Article
Use this order unless the topic needs a different flow:
1. early contextual blog link
2. first relevant tour link before midpoint
3. second supporting blog link in the middle
4. CTA link in the second half
5. related article links near the end

## Recommended Link Mix By Page Goal
- Awareness post: `3` blog links + `1` tour link
- Hybrid guide: `2-3` blog links + `2` tour links
- Comparison post: `2` blog links + `1-2` tour links
- Itinerary post: `3` blog links + `1-2` tour links

## Quick Decision Rule
If you are not sure where to link:
1. link to the best supporting blog guide
2. link to the strongest matching tour page
3. link to `all-tours.html` only when the user still needs a broader choice set
