# Reports

This folder holds synthesized outputs that combine context, audits, and performance signals into decisions.

## Purpose
Reports are for prioritization and tracking.

Use them to answer:
- what should we fix first
- what content should we create next
- what moved this month
- what still lacks input or review

- `current-priorities.template.md`
- `monthly-seo-status.template.md`
